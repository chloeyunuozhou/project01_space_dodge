SPACE DODGE

Dodge the stars. Survive as long as you can.

About the Game

Space Dodge is a fast-paced arcade game built with Python and Pygame. You pilot a spacecraft at the bottom of the screen while stars fall from above. Use the arrow keys to move left and right—avoid every star and see how long you can last. The longer you survive, the faster the stars come. How high can you score?

How to Play

  • Move your spacecraft left and right to avoid the falling stars.
  • Survive as long as possible—your time is your score.
  • If a star hits your craft, the game is over.

How to Run the Game

You need Python 3 and Pygame installed. From the project folder in a terminal:

# Install pygame if you haven't already
pip install pygame

# Run the game
python main.py

Make sure the resources folder is in the same directory as main.py, with bg.jpeg, crafts.jpg, and star.jpg inside it.
