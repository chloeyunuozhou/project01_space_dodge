SPACE DODGE V2

Salamander-style shooter · Dodge, collect power-ups, defeat the UFO.

About the Game

Space Dodge V2 is inspired by Konami's classic Salamander (1986, aka Life Force)—a vertical scrolling shooter. Pilot your ship at the bottom, dodge comets, and collect power-up capsules: Speed (faster movement), Spread (3-way shot), and Shield (temporary invincibility). At 90 seconds a UFO boss appears—shoot it 10 times to win. Background music plays when you start; use the Music button to mute.

How to Play

  • Move your spacecraft left and right to avoid the falling stars.
  • Survive as long as possible—your time is your score.
  • If a star hits your craft, the game is over.

Controls

← Move left
→ Move right

How to Run the Game

You need Python 3 and Pygame installed. From the project folder in a terminal:

# Install pygame if you haven't already
pip install pygame

# Run the game
python main.py

Make sure the resources folder is in the same directory as main.py, with bg.jpeg, crafts.jpg, and star.jpg inside it.
